# 新手快速开始

> 适用于 v0.0.8 开发树。v0.0.7 仍是当前正式稳定版；开发功能以实际源码和验收结果为准。

## 开始前

- Node.js **22.13+**、npm、Git。
- 只分析自己拥有或明确获授权的目标。
- 默认不需要 API Key，也不需要把材料发送到远程模型。
- 网站分析可能需要 Chrome/Chromium。

```bash
npm ci
npm run build
npm start
```

打开 <http://127.0.0.1:4173>。API 与 Web 同端口。启动会生成本地令牌，请勿提交 `data/`。

## 第一个静态网站任务

1. 在首页“把想法交给 Autopilot”输入：`分析 https://example.com 并生成一个可部署的静态网站`。
2. 如系统追问平台，选择 `Web / 静态网站`。
3. 阅读只读分析授权，选择“授权”。远程数据共享未明确要求时保持“仅本地”。
4. 检查目标契约：授权范围、禁止操作、预算、交付物和验收条件。
5. 点击“确认契约并生成计划”。
6. 检查计划是否包含分析、重建、构建、测试、打包、文档和独立验收。
7. 点击“确认计划并开始执行”。
8. 完成后点击“打开交付中心”，先读 `START-HERE.md`，再查看 `reports/ACCEPTANCE.json`。
9. 下载工件并核对 SHA-256；按教程打开 `artifacts` 中的 `index.html` 或部署到静态服务器。

示例 URL 仅用于说明流程。只有在你拥有或获授权时才替换为真实目标。

## 第一个本地材料分析

1. 先创建一个软件/固件/数据恢复项目，或在 Autopilot 首页新建项目。
2. 输入目标，例如：`只读分析这个旧软件，生成兼容性报告，不执行原程序`。
3. 上传合法样本；若使用本机路径，需满足 API 服务端对应目录白名单配置。
4. 选择目标平台并确认只读授权。
5. 确认契约与计划，观察真实子任务、证据和错误。
6. 非部署目标通常交付分析报告、使用说明、验收报告和哈希清单，不会强制反编译或构建。

## 看懂结果

- `COMPLETED`：规则验收通过；仍要阅读限制，不等于所有外部兼容性都已验证。
- `PARTIAL_SUCCESS`：有部分交付，但存在未通过检查或未完成项。
- `FAILED`：执行失败；查看步骤错误，不要只看任务标题。
- `WAITING_FOR_USER`：还需要材料或答案。
- `WAITING_FOR_APPROVAL`：系统等待你的显式确认，不能跳过。

## 常见问题

| 问题 | 处理 |
|---|---|
| 页面一直等待确认 | 契约和计划是两次确认；阅读后分别批准 |
| 提示路径越界 | 使用已上传文件，或让管理员配置对应分析器允许目录 |
| 提示远程模型未授权 | 保持 local-only，或在模型管理中明确授权远程 Provider |
| 交付中心没有文件 | 查看任务是否完成、是否仅报告、是否被阻塞 |
| 下载后校验失败 | 停止使用该工件，重新下载并对照清单；不要修改后继续传播 |
| 想停止任务 | 使用“暂停”或“取消”；已生成工件会保留 |
