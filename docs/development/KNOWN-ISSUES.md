# 已知问题与限制

最后更新：2026-11-27。适用范围：v0.0.8 正式版及后续开发树。状态以代码、分平台 CI 和发行记录为准；本文件不再维护第二份缺陷台账。

## 当前已实现能力（避免沿用过期限制）

- Ghidra Headless 12.2 与 JADX 1.5.3 已接入，并有官方工具已知答案 CI；覆盖范围受工具、格式、架构和预算限制，不代表所有样本。
- APK/ZIP 安全清单、AXML Manifest、DEX 表与原生库元数据可离线分析；JADX 反编译需要可用工具与授权样本。
- 网页采集覆盖 DOM、脚本、路由、表单、截图和同源网络元数据；HAR/PCAP/PCAPNG 可离线解析。
- Game Revival 使用 `revival-behavior/v1` 行为 IR，Pixelknight 与 Tron 原始浏览器客户端已有独立兼容证据；商业客户端仍不外推。
- Legacy Studio 支持只读老软件识别、兼容/许可诊断、数据恢复和独立工具生成，不执行未知原程序。
- Skill、CLI、MCP、REST、OpenAPI、Web 与桌面入口已随 v0.0.8 同步，MCP 共 54 个工具。
- 跨任务缓存、资源采样、内存/进程树指标、保留策略、取消和阶段恢复已实现；仍是有界工程机制，不是无限资源保证。

## 功能边界

- 静态分析和生成结果可能受文件截断、格式复杂度、加密内容、工具版本和预算影响；截断或未知内容应保持 `UNKNOWN`/`INFERENCE`。
- 网页采集不绕过登录、验证码、付费墙、DRM、反作弊、CSP 或访问控制；动态页面可能受渲染、同源和超时限制。
- 安全规则与 SBOM 是辅助证据，可能误报或漏报；不提供自动漏洞利用，未做在线 CVE 匹配时不宣称完成漏洞判定。
- L0-L7 只表示生成服务的实现与部署等级；目标行为、原客户端和协议兼容单独报告，默认未知不能因构建成功而升级。
- Legacy 兼容建议不是许可证恢复或授权；不执行未知原程序，不下载未经确认的外部依赖。
- 英文界面与文档覆盖仍不完整；未翻译内容不应被理解为完整本地化验收。
- 本地令牌等同本机 API 权限，不是多用户身份认证；不要暴露到不可信网络。

## 工程限制

- 重型构建和资源密集任务采用有界串行/预算策略；取消通常在阶段或工具边界生效，外部进程可能需等待自身超时或清理。
- Node `node:sqlite` 的实验性 API 提示不代表迁移失败，但升级时仍需完整备份、迁移校验和回滚演练。
- 大文件、深度目录和高熵内容受明确上限约束；达到上限应报告截断，不应宣称完整分析。
- 代码视图首次加载 Monaco 需要读取本地大文件；低内存环境可能有启动延迟。
- v0.0.8 已通过候选与正式发行验收；后续开发差异仍须以新冻结提交和 CI 为准。
