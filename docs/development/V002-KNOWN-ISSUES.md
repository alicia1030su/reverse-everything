# v0.0.2 已知问题与限制

最后更新：2026-11-24 UTC+8

## 环境限制

- 本机无 Docker、pnpm、Python、Rust/Cargo；容器由 CI 验证，Tauri 原型不能在本机直接构建。
- 无 Windows 代码签名证书；EXE 将明确标注未签名与 SmartScreen 风险。
- 可用内存约 20GB；默认单 Worker、单浏览器、顺序构建。

## 继承自 v0.0.1

- 无 Ghidra 反编译、APK/DEX、HAR/PCAP、多页面状态机、网站克隆。
- 暂停/取消在阶段边界生效。
- 单用户本地令牌不是多用户身份系统。
- 游戏兼容服务是独立回放实现，不是原始服务恢复。

## v0.0.2 风险

- 数据库迁移必须避免破坏 v0.0.1 数据，备份与回滚为发布阻塞项。
- 缓存跨项目共享可能泄露敏感证据，默认项目隔离。
- 进程树采样在 Windows 依赖 PowerShell/CIM，需限制采样频率并处理权限失败。
- Electron 包体积和内存高于 Tauri 理论值，必须实测，不能只引用宣传数据。
- Playwright 浏览器下载必须显式触发、校验并报告失败。
- MCP HTTP 远程暴露不在默认范围；默认仅回环 + 令牌。
