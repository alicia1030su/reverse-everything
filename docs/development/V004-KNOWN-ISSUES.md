## 硬件与固件

- 真实物理 USB 设备、实时捕获、驱动安装、串口实时读取与用户凭证未授权；相关能力不宣称已实测。
- 硬件只读枚举受 OS 权限与字段限制；串口不打开、不改 DTR/RTS，键盘报告捕获默认禁用。
- 固件为有界静态分析，不执行、不解包运行、不刷写；加密或高熵内容保持 `UNKNOWN`。
- 开发板复用 `hardware` 路由，固件镜像使用独立 `firmware` 入口；不提供额外登录、复位、控制线或刷写权限。

## 产品边界

- 网页兼容产物是静态预览，不是原后端或完整动态网站克隆。
- 游戏 L4 是独立状态化兼容服务，不是原始服务端恢复；L5 未实现。
- AI 无真实 Key 时只运行规则分析；Planner/Validator 受限，不宣称自动代码修复。
- Docker 默认无宿主 USB，不提供 privileged 或整目录设备映射。
- Windows 未签名安装包可能触发 SmartScreen；不伪造代码签名。

## 独立复审 P2（非阻断）

- macOS `ps` 输出接受 `60` 分钟/秒，需严格限制 `0..59`。
- APK `prepare` 成功后若任务在分析前中止，私有快照由任务临时目录保留策略兜底。
- 缓存 payload 在 SQLite 事务内 rename，不是崩溃原子替换；读取端有哈希/fencing 保护。
- 浏览器依赖版本漂移检查尚未实现。
- Windows/Linux 设备自由文本已改为单向哈希；离线用户快照仍可能包含设备可控文本，按不可信输入处理。

已修复并纳入回归：桌面 resource_samples 保留策略、PCAP 魔数歧义、UF2 非连续地址 O(n²)。
