逆向万物 API v0.0.4

完整机器可读规范：openapi-v0.0.4.json。所有业务请求使用 Bearer Token；错误格式为 {error:{code,message,requestId}}。

方法路径说明
GET/api/healthMinimal public health, product version and schema
GET/api/versionProduct and schema versions
GET/api/capabilitiesAdapters and entrypoints
GET/api/sessionEstablish the local session cookie
GET/api/statsPersisted project task evidence and adapter statistics
GET/api/adaptersList adapters and availability
GET/api/system/statusAPI worker browser MCP and adapter status
GET/api/system/browser/installBrowser installation status
POST/api/system/browser/installInstall Chromium after explicit confirmation
GET/api/resourcesCurrent API worker and desktop resource snapshots
GET/api/resources/historyPersisted resource samples
POST/api/resources/desktopRecord real Electron desktop process metrics; loopback-only and disabled in remote API mode
GET/api/hardware/capabilitiesRead-only local hardware platform capabilities
GET/api/hardware/doctorDiagnose local USB and serial enumeration without opening devices
GET/api/hardware/devicesList OS-visible USB device identities with serials redacted
GET/api/hardware/serialList serial ports without opening them or changing DTR/RTS
GET/api/projectsList projects (array with x-total-count)
POST/api/projectsCreate an authorized project
GET/api/projects/{id}Get project and uploads
DELETE/api/projects/{id}Delete inactive project with exact-name confirmation
POST/api/projects/{id}/uploadsStream upload and calculate SHA-256
POST/api/projects/{id}/tasksCreate a task with optional resource budget
GET/api/tasksList tasks (array with x-total-count)
GET/api/tasks/{id}Task stages evidence findings logs and artifacts
POST/api/tasks/{id}/{action}Pause resume cancel or retry at a safe checkpoint
GET/api/tasks/{id}/eventsSSE events with Last-Event-ID resume
GET/api/tasks/{id}/events/historyPersisted task event history
GET/api/tasks/{id}/evidencePaginated task evidence
GET/api/evidence/searchSearch persisted evidence across projects and tasks
GET/api/evidence/{id}Get evidence by ID
GET/api/tasks/{id}/artifact-manifestArtifact hashes and download paths
GET/api/tasks/{id}/artifacts/{name}Download task artifact
GET/api/tasks/{id}/reportDownload Markdown report
GET/api/cacheList cache entries
GET/api/cache/statsCache hit rate size and integrity counters
POST/api/cache/clearExplicit cache cleanup with confirmation
GET/api/cache/verifyVerify cache payload hashes
GET/api/retentionRetention policy
PUT/api/retentionUpdate retention policy
GET/api/maintenance/previewDry-run cleanup preview
POST/api/maintenance/applyApply cleanup with CLEAN confirmation
GET/api/maintenance/eventsRetention cleanup event history
GET/api/demo/traceDownload the bundled demo trace
GET/api/settingsRedacted AI settings
PUT/api/settingsUpdate AI settings and encrypted key
POST/api/settings/testTest the configured OpenAI-compatible model endpoint
GET/api/openapi.jsonOpenAPI document
GET/api/backupsList database backups
POST/api/backupsCreate a consistent database backup
GET/api/backups/{id}/verifyVerify backup digest, schema, SQLite integrity and foreign keys
GET/api/backups/{id}/eventsList backup lifecycle events
POST/api/backups/{id}/previewRestore a backup into a new isolated directory without switching the active database
POST/api/backups/{id}/restoreRestore a confirmed backup into a new isolated directory
