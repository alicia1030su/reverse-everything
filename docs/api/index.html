逆向万物 API v0.0.2

完整机器可读规范：openapi-v0.0.2.json。所有业务请求使用 Bearer Token；错误格式为 {error:{code,message,requestId}}。

方法路径说明
GET/api/healthHealth and real process metrics
GET/api/versionProduct and schema versions
GET/api/capabilitiesAdapters and entrypoints
GET/api/system/statusAPI worker browser MCP and adapter status
GET/api/resourcesCurrent API worker and desktop resource snapshots
GET/api/resources/historyPersisted resource samples
GET/api/projectsList projects (array with x-total-count)
POST/api/projectsCreate an authorized project
GET/api/projects/{id}Get project and uploads
DELETE/api/projects/{id}Delete inactive project with exact-name confirmation
POST/api/projects/{id}/uploadsStream upload and calculate SHA-256
POST/api/projects/{id}/tasksCreate a task with optional resource budget
GET/api/tasksList tasks (array with x-total-count)
GET/api/tasks/{id}Task stages evidence findings logs and artifacts
POST/api/tasks/{id}/{action}Pause resume cancel or retry at a safe checkpoint
GET/api/tasks/{id}/eventsSSE events with Last-Event-ID resume
GET/api/tasks/{id}/evidencePaginated task evidence
GET/api/evidence/{id}Get evidence by ID
GET/api/tasks/{id}/artifact-manifestArtifact hashes and download paths
GET/api/tasks/{id}/artifacts/{name}Download task artifact
GET/api/tasks/{id}/reportDownload Markdown report
GET/api/cacheList cache entries
GET/api/cache/statsCache hit rate size and integrity counters
POST/api/cache/clearExplicit cache cleanup with confirmation
GET/api/cache/verifyVerify cache payload hashes
GET/api/retentionRetention policy
PUT/api/retentionUpdate retention policy
GET/api/maintenance/previewDry-run cleanup preview
POST/api/maintenance/applyApply cleanup with CLEAN confirmation
GET/api/settingsRedacted AI settings
PUT/api/settingsUpdate AI settings and encrypted key
GET/api/openapi.jsonOpenAPI document
