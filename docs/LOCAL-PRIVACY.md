# Local Privacy 边界

Reverse Everything 是本地单用户工作台。隐私边界以实际代码路径、任务证据与用户确认记录为准，不以界面文案或模型承诺为准。

## 1. 默认本地处理

- 项目、上传、任务、证据、报告与产物默认保存在本机 `data/`。
- Legacy Studio 的只读识别、数据恢复和独立重建本身不调用远程 AI；若用户在共享任务引擎中显式启用远程 AI，必须同时具备有效、未撤销、未过期的项目授权，且授权目标、适配器和 `network-access` 操作与当前任务匹配。隐私 API 会显示是否存在有效授权，但不会把全局开关当作任务级授权。
- `legacy` 分析返回的隐私证据为 `localOnly=true`、`remoteAiUsed=false`、`networkRequired=[]`、`externalTools=[]`。
- 未配置 AI 时，确定性分析、规则诊断、恢复与重建仍可运行。

“本地”不等于“无风险”：本机日志、浏览器 localStorage、导出文件和生成项目仍可能包含敏感数据，应纳入备份与删除策略。

## 2. 远程 AI 与共享

远程模型默认关闭。启用远程共享必须同时满足显式配置、用户同意和项目授权范围；模型输出只能是 `INFERENCE`，不能替代工具证据。

Legacy Studio 当前不要求远程 AI。不得为了生成报告而把样本、个人数据或凭证发送给未授权端点。真实 AI Key、模型服务与 macOS 环境未验收时，不得宣称已完成端到端 AI 实测。

## 3. 网络与下载透明

- 网页分析只访问用户授权的 HTTP/HTTPS 目标，并执行 SSRF、DNS 与同源边界。
- 硬件枚举仅本机回环；远程 API 模式拒绝。
- 外部工具不自动安装。Wine、DOSBox、虚拟机、JRE、Visual C++ 运行库等只提供建议，由用户从官方来源核验并自行安装。
- 任何下载、外部工具调用或远程共享都应在任务记录中可见；未发生的步骤不能标记为完成。

## 4. 目录与设备权限

- 游戏扫描只读 `RE_GAME_ROOTS` 允许目录。
- Legacy 本机路径只读 `RE_LEGACY_ROOTS` 允许目录。
- stdio MCP 本地文件读取只允许 `RE_MCP_ALLOWED_ROOTS`；HTTP MCP 只接受 base64 内容。
- 不打开未授权 USB/串口，不捕获键盘，不刷写固件，不安装驱动。

## 5. 保留与删除

缓存、维护、备份与项目删除必须显式确认；活动任务的临时文件与日志受保护。保留策略不会自动删除原始上传或正式产物。清理前先预览，导出数据后再删除，并核对备份完整性。

## 6. 用户检查清单

1. 确认目标合法授权与目录白名单。
2. 确认远程 AI 关闭，或已明确同意数据共享。
3. 查看证据中的 `localOnly`、`remoteAiUsed` 与 `limitations`。
4. 下载产物后核对 SHA-256。
5. 在隔离环境运行生成代码，不执行未知原程序。
