# 逆向万物安全模型

## 1. 资产与威胁

平台处理来源不可信的软件、网页、日志、反编译文本和模型输出。主要资产：用户文件、授权会话、API Key、本地数据库、分析产物、Agent 指令与执行权限。

威胁包括：SSRF/DNS 重绑定、路径穿越、压缩炸弹、恶意网页、提示词注入、秘密泄露、任意代码执行、任务失控、跨站请求、产物污染与越权分发。

## 2. 授权门禁

- 创建项目必须显式 `authorizationConfirmed=true`。
- 任务在 AUTHORIZATION_CHECK 阶段再次验证并记录证据。
- 本地 URL 需 `allowLocal=true` 且 `confirmLocal=true`。
- 不绕过登录、验证码、付费、DRM、反作弊或第三方账号验证。
- 主动安全测试默认关闭；v0.0.1 只做被动 HTTP 与静态规则。
- 商业工具仅使用用户合法授权版本，不打包许可证或绕过激活。

## 3. 输入与执行

- 默认上传上限 100MB；流式写入随机文件名；SHA-256 追踪。
- 文件扩展名与 MIME 不是可信证明；按 magic/header 识别。
- 不执行上传的未知程序。
- 网页在 Chromium 中运行，但仅访问已授权同源；禁用跨源子资源。
- 游戏验证只启动本项目根据证据生成的 Node 服务，不启动原客户端二进制。
- 子进程有超时与退出清理；生成服务仅绑定 127.0.0.1。

## 4. 网络

- 仅 HTTP/HTTPS；URL 不允许内嵌凭证。
- 默认拒绝 127/8、10/8、172.16/12、192.168/16、169.254/16、100.64/10、0/8、组播/保留地址、IPv6 loopback/link-local/ULA。
- 公网仅允许 80/443；本地显式授权可指定演示端口。
- 每次重定向重新解析与验证。
- HTTP 使用固定已验证 IP 的 lookup；浏览器使用 host-resolver-rules。
- 同源检查同时覆盖导航和子资源；HAR/响应体不默认保存。

## 5. 本地访问控制

- API 默认绑定 127.0.0.1；容器内绑定 0.0.0.0，但宿主端口仅映射 127.0.0.1。
- Host 只接受 localhost/127.0.0.1；Origin 必须与 Host 同源。
- 随机 32 字节本地令牌存 `data/local-token`（0600）。
- Web 使用 HttpOnly、SameSite=Strict cookie；CLI/MCP 使用 Bearer token。
- 业务 API 不接受未认证请求；静态 HTML/JS 不含用户数据。

## 6. 秘密与隐私

- API Key 使用 AES-256-GCM 加密；密钥存 `data/secret.key`（0600）。
- 设置接口只返回 `hasApiKey`，不返回明文。
- 日志与报告脱敏 Bearer token、api_key/password/secret/token 模式。
- 文件字符串与文本预览对疑似凭证脱敏，并记录 `stringsRedacted=true`。
- 默认本地存储；AI 关闭。远程模型必须显式允许数据共享。
- 模型请求仅发送有界分析摘要，不发送原始上传文件或凭证。
- 公开仓库不得包含 `data/`、`.env`、真实凭证、用户上传或商业资源。

## 7. 不可信内容与提示词注入

- 外部内容标为数据，不进入系统指令。
- AI system prompt 要求将目标内容视为不可信数据，不声称未验证事实。
- 工具权限不由模型文本授予；所有动作通过固定 API/Adapter 契约。
- 模型输出统一记为 INFERENCE；只有可重复工具测试能记为 VERIFIED。
- 前端使用 React 文本渲染，不把证据 HTML 注入页面；Monaco 只读。

## 8. 安全分析结果

每条候选发现包含：标题、分类、等级、模块/位置、依据、前提、证据 ID、置信度、修复建议与状态。默认 `needs_review`，不标为已确认漏洞。报告支持 Markdown、JSON/manifest、SARIF 2.1.0。

## 9. 清理与审计

- 操作与阶段事件持久化；输入哈希和产物哈希可核对。
- 删除项目需发送精确名称确认；级联删除任务目录和上传文件。
- 日志限长，任务列表限 200 条；阶段输出与证据仍有增长风险，保留策略见 Roadmap。
- 不自动清理用户数据；避免误删。

## 10. 已知边界

- 本地令牌不是多用户身份系统；拿到本机令牌等于本地 API 权限。
- 浏览器仍执行目标 JavaScript；容器/OS 隔离不能替代谨慎授权。
- DNS 固定不能防止目标网页自身发起合法的同源恶意行为。
- 静态规则存在误报/漏报；依赖漏洞在线匹配未启用。
- 运行时原生程序沙箱、容器 seccomp 细粒度策略、跨任务缓存隔离与自动内存熔断为后续工作。
