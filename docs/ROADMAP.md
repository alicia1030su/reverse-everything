# 逆向万物路线图

所有日期均为规划，不代表已交付。状态以代码、测试和发布记录为准。

## v0.0.1：可验证基础平台

- Monorepo、Web/API/Worker/CLI/MCP。
- 项目、上传、哈希、SQLite 任务、检查点、SSE。
- 网页采集、文件静态分析、基础安全、可选 AI。
- 自编写游戏协议推断、独立兼容服务与 E2E。
- Docker Compose、CI、文档、真实示例。

## v0.0.2：分析效率

跨任务输入哈希缓存、增量证据索引、保留策略、批量任务、Worker 并发与资源指标、内存熔断。

## v0.0.3：网页深度重建

多页面交互录制、路由/状态机、HAR 导入、视觉对比、API 模拟、测试驱动修复；仅处理授权内容。

## v0.0.4：原生分析

Ghidra Headless provider、函数/调用图、类型与伪代码证据、PE/.NET/ELF/Mach-O 深入解析；运行时执行需隔离。

## v0.0.5：移动应用

Android 资源、Manifest、DEX、组件分析；APK/AAB 适配。iOS 仅静态资源与可合法分析结构，深度能力另行验证。

## v0.0.6：协议理解

HAR/PCAP/WebSocket/JSON/XML/Protobuf/二进制样本、字段关联、请求响应匹配、状态机、本地回放。

## v0.0.7：游戏复活

Unity/Unreal/Godot/Cocos 识别、资源包、存档、协议恢复、离线流程；L0–L5 逐级证据，不承诺每款游戏达到 L5。

## v0.0.8：安全研究

SBOM 漏洞匹配、更多 CWE/OWASP 规则、SARIF 质量、授权实验范围、速率/超时/停止开关、修复后复测。

## v0.0.9：多 Agent 协同

Planner/Inspector/Protocol/Reconstruction/Security/Validation/Reviewer 共享结构化状态；多模型路由、费用与 token 预算。

## v0.1.0：完整工作流

网页、软件、游戏的更高自动化；跨层证据与行为对比、可复现构建、失败项目标注。

## v0.2.0 → v1.0.0

分布式 Worker、插件生态、更多平台、可复现发布、成熟数字保存与合规治理。

## 明确不做

- 无授权扫描、绕过访问控制、自动窃取数据、漏洞批量利用。
- 自动分发无授权商业资源。
- 把模型猜测当作事实。
- 用占位按钮、随机进度、预写兼容服务冒充自动恢复。
