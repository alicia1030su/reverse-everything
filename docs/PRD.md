# 逆向万物 v0.0.1 产品需求文档

## 1. 定位与目标

逆向万物是本地单用户的 AI 辅助逆向工程与数字软件兼容重建工作台。首个版本证明一条真实闭环：

**创建授权项目 → 上传/输入目标 → 持久化分析 → 证据与发现 → 验证 → 报告/产物导出**。

核心原则：证据驱动、自动化优先、可验证、可恢复、可扩展、安全隔离。不能可靠实现的能力必须标为 UNKNOWN 或列入 Roadmap。

## 2. 用户与场景

- 开发者：理解自己维护或获授权的网页、脚本和二进制结构。
- 安全研究员：对自己拥有或明确授权的目标做被动检查与静态复核。
- 数字保存/兼容开发者：用合法保留的客户端与通信记录生成独立本地兼容服务。
- Agent/自动化用户：通过 CLI 或 MCP 调用与 Web 相同的任务契约。

非目标：匿名多租户、公开托管、无授权扫描、绕过登录/验证码/付费/DRM/反作弊、自动漏洞利用、商业游戏资源分发、保证恢复所有软件。

## 3. v0.0.1 范围

### P0（9/15 = 60%）

1. 本地 Web 控制台与真实 API 对接。
2. 项目创建、授权确认、文件上传、SHA-256。
3. SQLite 持久任务、阶段检查点、暂停/恢复/取消/失败重试。
4. SSE 状态、日志、证据与产物查看。
5. Playwright 网页采集：DOM、脚本、路由候选、表单、截图、同源网络元数据。
6. 文件静态分析：格式、PE/ELF/Mach-O 元数据、字符串、ZIP 清单、SBOM。
7. 基础安全检测与 Markdown/JSON/SARIF 导出。
8. 自编写迷你游戏回放推断、兼容服务生成、E2E 验证。
9. CLI、MCP、Docker Compose、CI 与文档。

### P1

10. OpenAI 兼容模型配置、加密密钥、本地/远程数据同意、INFERENCE 标记。
11. 多模型任务分配与细粒度费用预算。
12. 证据关系图、协议字段/状态机与游戏复活等级视图。
13. 输入保留策略与项目删除确认。
14. 可配置 Worker 并发与资源指标接口。
15. 英文 i18n 与无障碍完整审计。

P1 不等于未交付即可假装完成；每项状态以 `PROGRESS.md` 与测试记录为准。

## 4. 核心流程

1. 用户选择网页、软件、游戏或安全入口。
2. 用户确认合法授权；本地目标需额外勾选。
3. 系统保存输入并计算哈希。
4. Worker 按统一状态机执行：INTAKE → CLASSIFY → AUTHORIZATION_CHECK → PLAN → PREPARE → ANALYZE → COLLECT_EVIDENCE → MODEL_BEHAVIOR → RECONSTRUCT → VALIDATE → REPORT → EXPORT → COMPLETED。
5. 用户通过 SSE 观察真实阶段，并可暂停、恢复、取消、重试。
6. 结论分为 EVIDENCE / INFERENCE / UNKNOWN / VERIFIED。
7. 下载报告、证据清单、SARIF、manifest 与重建产物。

## 5. 页面与验收

- 总览：统计全部来自 API；空状态不是假数据。
- 创建项目：四入口、URL/文件、授权与本地确认。
- 任务工作台：阶段、当前工具、日志、控制按钮、证据/发现/报告/产物。
- 证据探索器：文件树、关系图、只读本地 Monaco；原始内容不渲染为 HTML。
- 协议中心：消息类型、字段出现次数、转换与未知项。
- 复活实验室：等级、E2E 检查、独立重建声明。
- 安全中心：候选发现、证据、置信度与修复建议。
- 验证中心：真实检查、限制、原始截图；无克隆时不伪造对比。
- 设置：模型端点、模型名、密钥、远程数据同意、工具可用性。

## 6. 状态与恢复

- CREATED/QUEUED/RUNNING/PAUSED/BLOCKED/FAILED/CANCELLED/PARTIAL_SUCCESS/COMPLETED。
- 阶段状态与输出持久化；Worker 重启后未完成阶段重新排队。
- 已完成阶段在同一任务重试时复用；跨任务缓存为后续优化。
- 暂停/取消在阶段边界生效；重型阶段自身有超时。
- 有界单 Worker 队列；默认不并行执行重型分析。

## 7. 验收标准

- 无 AI Key 时文件、网页、安全、协议规则仍可运行。
- 文件任务能创建、完成、失败、重试并保留输入哈希。
- 网页任务对自编写站点产出真实截图、DOM、NDJSON 和报告。
- 游戏任务从 `captured-trace.json` 生成服务，启动后完成 hello/login/move/logout。
- CLI/MCP/Web 返回相同任务 ID 与契约。
- 本地令牌、Origin/Host、SSRF、ZIP 路径穿越/压缩炸弹测试通过。
- 安全候选有证据、偏移、置信度、建议；正常样本不误报。
- README 与真实能力一致；未实测功能明确标注。

## 8. 质量门禁

P0 阻塞缺陷为 0；核心链路测试 100% 执行；不得删除失败测试、伪造进度或把模型判断当验收。Docker 必须由可用的构建/运行环境验证；本地缺 Docker 时可由 GitHub Actions 的 Docker job 提供证据。
