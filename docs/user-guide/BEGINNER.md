# 小白使用指南

逆向万物帮助你以可追溯的方式分析自有或明确获授权的设备、软件、固件、网页和通信记录。你不需要阅读源码或手动组合多个分析器。

## 第一次使用

1. 打开 Web 或桌面端，阅读首次使用提示。
2. 确认你拥有分析目标的合法权限。
3. 点击“开始智能分析”。
4. 选择目标类型：PS5、Xbox、Android TV、USB、固件、Windows/Linux 软件、Android 应用、网页、游戏、协议或安全分析。
5. 按页面提示提供文件、设备摘要或授权 URL。
6. 点击“开始智能分析”，系统会自动检测环境、选择可用分析器并生成计划。
7. 在任务工作台查看真实步骤、日志、证据和资源消耗。
8. 在报告中切换“普通用户”和“专业”视图，导出 Markdown、JSON 或 HTML。

## 三种模式

- **小白模式**：只需选择对象、确认授权、开始分析、查看报告。
- **专业模式**：可选择分析器、深度、输出、模型和预算。
- **AI Agent 模式**：可通过 MCP、Skill、API 或 CLI 创建和管理受限任务。

所有模式共用同一套授权、安全和预算机制。

## 如何理解结果

- **已实现**：软件包含该能力。
- **已验证**：有可重复测试或真实工具证据。
- **部分支持**：只覆盖部分链路。
- **需要外部工具**：例如 Ghidra、JADX 或 Chromium。
- **需要真实设备**：当前只有档案、指引或离线样本。
- **不支持 / 未知**：不要把它当作成功或失败结论。

## 常见问题

- **没有安装 Ghidra/JADX 能用吗？** 可以使用内置静态分析；需要反编译时会明确提示安装官方工具。
- **为什么任务停止？** 查看任务错误说明，通常会指出缺失依赖、权限、预算或输入限制。
- **AI 的结论可信吗？** AI 文本是推断，不是事实；请查看原始证据并在隔离环境验证。
- **会修改我的设备吗？** 默认只读，不刷写、不安装驱动、不发送未知硬件指令。
