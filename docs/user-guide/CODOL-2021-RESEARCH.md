# CODOL 2021 研究档案

更新：2026-11-26。状态：研究档案 / 未实现兼容服务。

## 结论

本项目没有 CODOL 2021 最终客户端、资源、协议记录或授权，因此不能声明支持 CODOL，也不能把旧版本成果当作 2021 最终版兼容结论。当前仅推进通用引擎、公开资料核验和材料需求清单。

## 公开资料核验

- 公开资料普遍记载 CODOL 于 2021-08-31 停止运营；百科类资料列出 `V2.3.1.10`，但缺少可复核的最终安装包、构建清单和哈希，不能作为已验收客户端身份。
- CoDOL Classic 公开关联仓库 `nucleur16/cod-offline-1.1.1.13` README 明确针对 **1.1.1.13** 客户端，将 Demonware lobby 与 match server 嵌入游戏进程，提供 bot、Zombies、Survival、Spec Ops。它不是 2021 最终版，也不是独立商业服务端恢复。
- 该仓库声明 match server 源自 CoD4x，适用 AGPL-3.0；构建需要用户合法拥有的 1.1.1.13 安装。仓库许可不等于游戏客户端、地图、音视频、商标或商业运营授权。
- OpenSpy Core 的公开架构可作为协议服务分层参考，但仓库许可与目标游戏授权必须单独核查；本项目不复制其受保护代码。
- OpenRA 使用 GPL-3.0 引擎与模组资产分离的架构，说明“引擎开源”不等于“原游戏资产可公开分发”；本项目只借鉴模块化/数据驱动设计，不复制资产。

## 2021 最终版所需材料

1. 合法保留的最终客户端安装目录与来源/授权说明。
2. 启动器、主程序、DLL、配置、资源清单及版本元数据。
3. 每个文件的 SHA-256 与构建版本对应关系。
4. 引擎/模块结构与公开资源格式说明。
5. 合法可用的历史通信记录及采集授权。
6. 目标游戏模式、账号/大厅/房间/战斗/结算协议证据。
7. 第三方代码、样本与资源的许可证和再分发范围。
8. 是否允许研究、独立实现、社区部署与公开运营的书面授权。

## 阻塞与下一步

在材料 1-8 未满足前，CODOL 等级保持 UNKNOWN/BLOCKED，不生成针对该商业协议的兼容实现。通用引擎使用完全自有的 FPS/RPG 样本完成 L7 验收。
