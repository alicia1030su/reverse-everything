# Windows 桌面版（v0.0.5）

## 安装

1. 获取 `Reverse-Everything-Setup-0.0.5-win-x64.exe`，核对发行清单中的 SHA-256。
2. 运行安装程序，选择安装目录。
3. 启动“逆向万物”。首次使用会显示只读、授权、AI、设备风险与隐私说明。

便携版为 `Reverse-Everything-Portable-0.0.5-win-x64.zip`，解压后运行 EXE，不创建开始菜单快捷方式。

安装包未代码签名时，Windows SmartScreen 可能提示未知发布者；请核对来源与哈希，不要关闭系统安全功能。

## 数据与升级

- 默认数据位于应用数据目录中的 `data/`。
- 升级到 v0.0.5 前备份整个 `data/`。
- v0.0.5 使用 Schema 4；迁移失败时保留备份和错误信息。
- API 与 Electron 均使用单实例保护；第二次启动会聚焦已有窗口。

## 安全边界

- 默认只读，不刷写、不安装驱动、不发送未知硬件指令。
- USB Type-C 外形不是调试依据。
- 远程 AI 数据共享默认关闭。
- 主机研究等级 C0-C5 是证据等级，不是权限或破解能力。
