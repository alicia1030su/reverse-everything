# 从 v0.0.1 升级

1. 停止 v0.0.1 API 和 Worker。
2. 备份整个数据目录，尤其是 SQLite、`secret.key`、上传和任务产物。
3. 启动 v0.0.2。首次打开数据库会自动执行事务迁移，并在 `data/backups/` 生成迁移前 SQLite 备份。
4. 检查 `/api/version` 的 `schemaVersion=2`、项目/任务/证据/报告和加密设置。
5. v0.0.2 新表不影响旧数据读取；回滚时停止服务并恢复迁移前备份。

迁移保留项目/Task ID、上传哈希、证据引用和加密设置。不得通过删除旧数据库“修复”迁移。缓存可随时禁用或清理；原始上传和正式报告不自动删除。
