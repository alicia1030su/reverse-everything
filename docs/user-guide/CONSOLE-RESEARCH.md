# 主机研究实验室指南

主机研究实验室用于管理游戏主机和开放式嵌入式设备的合法研究档案、证据等级、USB 连接诊断、公开固件样本和兼容性报告。它不提供越狱、权限提升、安全启动绕过、DRM 绕过或自动漏洞利用。

## 支持的设备类别

- PlayStation 5、PS5 Slim、PS5 Pro、PlayStation 4
- Xbox Series X、Series S、Xbox One
- Android TV、Android 电视盒子
- 其他开放式嵌入式设备

设备出现在目录中不代表已经支持其内部系统分析。具体能力以设备能力矩阵和证据等级为准。

## C0-C5 证据等级

| 等级 | 含义 |
|---|---|
| C0 | 已建立主机档案 |
| C1 | 已记录设备身份信息与至少一份官方资料（不表示设备已验证） |
| C2 | 已确认合法可用的设备接口 |
| C3 | 完成公开固件或自有应用的静态分析 |
| C4 | 在授权开发环境中完成应用测试或兼容性验证 |
| C5 | 在自有实验设备中完成经过验证的独立兼容实现 |

等级由证据累计计算，不能通过手动填写提高。用户提交的证据固定记为 `USER_RECORDED`，只能支持到 C1；C2 及以上必须由可信后端验证的证据（`TOOL_VERIFIED`）支持。缺少证据时保持较低等级。

## USB 连接诊断

系统只根据你提供的只读枚举摘要判断：

- 操作系统是否识别设备。
- 标准描述符是否可读。
- 是否存在普通设备接口。
- 当前拓扑是否受支持。
- 是否需要官方开发环境或离线样本。
- 是否存在硬件安全风险。

USB Type-C 接口的物理形态不能作为调试依据。不支持普通零售主机对主机连接；不要使用可能造成电气损坏的不合规连接线。

## 研究流程

1. 创建设备档案，记录制造商、系列、型号、硬件版本和系统版本。
2. 保存官方资料和用户主动提供的信息。
3. 如合法可用，记录只读枚举或授权接口观察。
4. 导入有合法来源和 SHA-256 的固件或应用样本进行离线静态分析。
5. 在官方获批开发环境中完成测试并保存证据。
6. 生成普通用户/专业双视图报告。

## 边界

- 不自动识别未经验证的主机型号或系统版本。
- 不打开未知 USB 接口，不发送控制传输。
- 不安装驱动、不刷写、不绕过认证或平台保护。
- 真实设备未提供时，相关等级保持 `BLOCKED` / `UNKNOWN`。
