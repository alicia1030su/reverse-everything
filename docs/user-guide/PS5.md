# PS5 主机研究指南

逆向万物支持建立 PS5、PS5 Slim、PS5 Pro 和 PS4 研究档案，整理官方资料、合法固件样本、静态分析证据和兼容性报告。

## 可以做什么

- 记录型号、硬件版本、系统版本和用户主动提供的设备信息。
- 关联 PlayStation Partners 等官方公开资料。
- 管理有合法来源的公开固件或自有实验样本。
- 对样本进行哈希、格式、结构、字符串、熵和组件线索分析。
- 生成带 C0-C5 证据等级的研究报告。

## 不能做什么

- 不自动越狱、提升权限、绕过安全启动或 DRM。
- 不把零售 USB-C 端口当作调试接口。
- 不支持普通零售 PS5 对主机连接。
- 不提供电气改造、不合规线缆或未知接口指令。
- 不在未授权设备上执行操作。

## 官方开发环境

PlayStation 开发硬件、SDK 和文档通常需要 Sony 批准，并受计划条款和保密协议约束。请从 [PlayStation Partners](https://partners.playstation.net/) 等官方入口了解申请条件。仓库中的链接和说明不构成访问授权。

## 建议流程

1. 建立 C0 档案并保存官方资料。
2. 在合法授权范围内记录设备身份与官方资料，达到 C1（不表示设备已验证）。
3. 如获批开发环境存在合法可用接口，保存观察证据，达到 C2。
4. 分析合法固件或自有应用样本，达到 C3。
5. 在获批开发环境完成测试，达到 C4。
6. 仅在自有实验设备完成独立兼容实现后，才可达到 C5。

未获得真实设备或开发环境时，请保持对应等级为 `BLOCKED`，不要用模拟结果代替实机验证。
