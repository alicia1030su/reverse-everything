# 反模板保留样本

这些样本用于证明生成器消费目标行为，而不是仅替换游戏名称。
- `duel`：60 生命、3 次命中击杀、250ms 冷却、先得 3 分获胜、允许重生。
- `survival`：30 生命、无重生、每次采集 2 个草药、消耗 1 个草药治疗 15 点、采集总数达到 6 结束。
- `last-standing`：无重生、攻击淘汰玩家，由最后存活者获胜。
- `min-three`：至少 3 名玩家才能开局，用于验证人数门槛与多人验证 harness。
- `edge-actions`：包含零冷却、超远射程、多攻击、采集和治疗动作，用于验证运行时条款参数化覆盖。

`behavior.json` 是样本的功能规格，不是原始服务端源码。测试独立保留预期结果，检查扫描证据、规格、生成配置、生成引擎与实际联机行为。它们仍使用项目内部 WebSocket 客户端，不能作为原游戏客户端兼容证据。
