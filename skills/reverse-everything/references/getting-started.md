# Getting Started

1. Install the CLI TGZ or start the server/desktop app.
2. Set `RE_API_URL` (default `http://127.0.0.1:4173`) and `RE_DATA_DIR` if non-default.
3. Run `node scripts/check-environment.mjs`.
4. Create an authorized project and task through MCP, CLI or API.
5. Poll the same task ID and export the report.

The Skill does not contain credentials. Never place API keys in SKILL.md or config examples.
